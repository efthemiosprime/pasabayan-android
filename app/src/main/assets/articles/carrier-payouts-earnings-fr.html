Paiements et revenus des transporteurs

En tant que transporteur sur Pasabayan, vous gagnez de l'argent en livrant des colis pour les expéditeurs le long de vos itinéraires de voyage. Ce guide explique comment configurer vos paiements, comprendre vos revenus et suivre vos gains.

Configuration des paiements (Stripe Connect)

Avant de pouvoir recevoir vos gains, vous devez compléter l'inscription à Stripe Connect. Il s'agit d'une configuration unique qui relie votre compte bancaire pour les paiements automatiques.

Étape 1 : Accéder à la configuration des paiements

Ouvrez l'application Pasabayan et allez dans l'onglet Profil → section Paiements → Configuration des paiements.

Étape 2 : Démarrer l'inscription

Appuyez sur le bouton « Configurer ». Vous serez dirigé vers la page d'inscription sécurisée de Stripe dans votre navigateur. Si vous avez déjà commencé sans terminer, vous verrez un bouton « Continuer la configuration » à la place.

Étape 3 : Compléter la vérification Stripe

Stripe vous demandera de fournir :

  • Vérification d'identité : Pièce d'identité émise par le gouvernement pour la conformité KYC (Know Your Customer)
  • Coordonnées bancaires : Votre compte bancaire où les paiements seront déposés
  • Vérification d'adresse : Confirmation de votre adresse actuelle
  • Informations fiscales : Détails fiscaux requis pour votre région
Étape 4 : Retourner à l'application

Une fois l'inscription terminée, retournez à l'application Pasabayan. Votre statut de paiement sera vérifié automatiquement. Vous verrez votre statut passer à « Actif » avec un bouton « Voir le tableau de bord ».

Traitement sécurisé : Toutes les informations financières sont traitées par Stripe, un processeur de paiement certifié PCI DSS Niveau 1. Pasabayan ne stocke jamais directement vos coordonnées bancaires.

Statuts de configuration des paiements

  • Non inscrit : Vous n'avez pas encore commencé la configuration — appuyez sur « Configurer » pour débuter
  • Incomplet : Vous avez commencé l'inscription sans la terminer — appuyez sur « Continuer la configuration » pour reprendre
  • Actif : Entièrement configuré et prêt à recevoir des paiements — appuyez sur « Voir le tableau de bord » pour gérer votre compte

Comment êtes-vous payé

Flux de paiement

  1. Livraison jumelée : Le colis d'un expéditeur est jumelé avec votre trajet et les deux parties confirment
  2. L'expéditeur paie : L'expéditeur effectue le paiement, qui est autorisé (retenu) par Stripe
  3. Vous livrez : Récupérez le colis à l'aide du code de collecte à 6 chiffres et livrez-le à destination
  4. Livraison confirmée : L'expéditeur vous fournit le code de confirmation de livraison pour compléter la remise
  5. Paiement capturé : Une fois la livraison confirmée, le paiement est capturé et vos gains sont traités
  6. Paiement transféré : Stripe transfère automatiquement vos gains vers votre compte bancaire connecté
Important : Vous devez compléter l'inscription à Stripe Connect avant de pouvoir recevoir des paiements. Configurez cela avant d'accepter votre première livraison.

Comprendre vos revenus

Structure des frais

Pour chaque livraison, voici comment l'argent circule :

  • Prix de livraison convenu : Le prix de base convenu entre vous et l'expéditeur
  • Frais de service transporteur : 5 % du prix convenu est déduit à titre de frais de plateforme
  • Vous recevez : Le prix convenu moins les frais de service de 5 %
  • Pourboires : Les expéditeurs peuvent ajouter un pourboire après la livraison — les pourboires vous reviennent intégralement sans aucune déduction

Exemple détaillé

Pour un prix de livraison convenu de 100 $ CAD :

  • Prix convenu : 100,00 $
  • Frais de service (5 %) : -5,00 $
  • Vous recevez : 95,00 $
  • Si l'expéditeur donne 10 $ de pourboire : 95,00 $ + 10,00 $ = 105,00 $ au total
Conseil : Tous les frais sont affichés de manière transparente avant de confirmer une livraison. Il n'y a aucuns frais cachés.

Consulter vos revenus

Historique des transactions

Suivez tous vos gains grâce à votre historique de transactions :

  1. Allez dans Profil → section Paiements → Historique des transactions
  2. Filtrez par rôle : appuyez sur « Transporteur » pour voir uniquement vos gains
  3. Appuyez sur une transaction pour voir les détails complets

Détails de la transaction

  • Résumé des gains : Revenus de livraison, déduction des frais de service et montant final reçu
  • Statut du paiement : Si le paiement a été traité, est en attente ou complété
  • Chronologie : Progression du statut de la création à la complétion
  • Info livraison : Détails du colis, itinéraire et informations sur l'expéditeur
  • Montant du pourboire : Toute gratification ajoutée par l'expéditeur

Tableau de bord Stripe Express

Pour une vue complète de vos finances, accédez à votre tableau de bord Stripe Express :

  1. Allez dans Profil → section Paiements → Configuration des paiements
  2. Appuyez sur « Voir le tableau de bord »
  3. Consultez votre solde, l'historique de vos paiements et les détails de votre compte bancaire directement sur Stripe

Statuts des paiements

Chaque paiement passe par ces étapes :

  • En attente : Le paiement est programmé mais pas encore traité
  • En traitement : Le paiement est en cours de transfert vers votre banque
  • Complété : Les fonds ont été déposés dans votre compte bancaire
  • En suspens : Le paiement est temporairement retenu — contactez le support si cette situation persiste
  • Échoué : Le paiement n'a pas pu être traité — vérifiez vos coordonnées bancaires dans le tableau de bord Stripe
Délai de paiement : Après la confirmation de la livraison, les paiements sont généralement traités dans un délai de 2 à 5 jours ouvrables, selon votre banque et votre région. Vous pouvez vérifier le délai exact dans votre tableau de bord Stripe Express.

Reçus

Téléchargez des reçus pour vos dossiers et vos déclarations fiscales :

  1. Allez dans Profil → section Paiements → Reçus
  2. Parcourez votre historique de reçus
  3. Appuyez sur un reçu pour voir le document PDF complet

Détails du reçu

  • Numéro de reçu et date
  • Itinéraire de livraison (ville de collecte → ville de livraison)
  • Montant des gains du transporteur (pourboires inclus)
  • Ventilation des frais de service
  • Informations sur l'expéditeur
Conseil : Conservez vos reçus pour vos déclarations fiscales. Vos reçus de transporteur indiquent exactement ce que vous avez gagné pour chaque livraison.

Pourboires des expéditeurs

Les expéditeurs peuvent ajouter un pourboire après la livraison en guise de remerciement pour un excellent service. Les pourboires sont :

  • 100 % à vous — aucuns frais de plateforme ne sont déduits des pourboires
  • Traités séparément par Stripe
  • Inclus dans les détails de vos transactions et les totaux de vos reçus

Questions fréquentes

Quand puis-je commencer à recevoir des paiements?

Dès que votre inscription à Stripe Connect est terminée et que votre statut indique « Actif ». Assurez-vous de configurer cela avant d'accepter des livraisons.

Pourquoi mon paiement est-il en suspens?

Les paiements peuvent être retenus si Stripe nécessite une vérification supplémentaire ou s'il y a un problème avec la transaction. Consultez votre tableau de bord Stripe Express pour plus de détails, ou contactez le support.

Puis-je changer mon compte bancaire?

Oui. Accédez à votre tableau de bord Stripe Express depuis Profil → Configuration des paiements → Voir le tableau de bord pour mettre à jour vos coordonnées bancaires.

Comment voir mes gains totaux?

Utilisez l'historique des transactions filtré sur « Transporteur » pour les gains dans l'application, ou consultez votre tableau de bord Stripe Express pour un aperçu financier complet incluant l'historique des paiements.

Quel est le prix minimum de livraison?

Le prix minimum convenu de livraison est de 5,00 $ CAD. Cela garantit une rémunération équitable pour les transporteurs.

Besoin d'aide?

Si vous avez des questions sur vos paiements ou vos revenus :

  • Consultez votre historique des transactions pour les détails spécifiques à chaque livraison
  • Accédez à votre tableau de bord Stripe Express pour les informations de paiement et bancaires
  • Soumettez un ticket de support via l'application pour les questions de facturation
