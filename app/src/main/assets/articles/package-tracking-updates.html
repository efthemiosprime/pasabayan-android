Package Tracking and Updates

Stay informed every step of the way with Pasabayan's real-time tracking system. Monitor your deliveries from pickup to delivery with live updates.

Tracking Your Package

For Shippers

Where to Find Tracking

  • Go to Packages tab
  • Select your active delivery
  • View "Deliveries" section
  • See real-time status updates

For Carriers

Managing Deliveries

  • Go to Bookings tab
  • View active deliveries
  • Update status as you progress
  • Share location updates

Delivery Statuses

Request Status

  • Open: Request created, awaiting match
  • Matched: Carrier assigned to delivery
  • Pending: Awaiting confirmation

Delivery Progress

  • Confirmed: Booking confirmed, ready for pickup
  • Picked Up: Package in carrier's possession
  • In Transit: On the way to destination
  • Delivered: Successfully delivered

Exceptions

  • Cancelled: Delivery cancelled by user
  • Declined: Request declined by carrier

Real-Time Tracking

GPS Location Sharing

  • Carriers share live location during transit
  • View carrier's current location on map
  • Estimated arrival time updates
  • Navigation assistance available
Privacy Note: Location sharing only occurs during active deliveries. Carriers can disable location sharing in settings.

Push Notifications

Automatic Updates

Receive notifications for:

  • Request matched with carrier
  • Pickup confirmed
  • Package in transit
  • Estimated arrival
  • Delivery completed
  • Rating requests

Managing Notifications

  1. Go to Settings in Profile
  2. Tap "Notifications"
  3. Customize delivery alerts
  4. Choose notification types

Pickup Confirmation

Confirmation Code System

When your package is ready for pickup:

  1. Shipper generates pickup code in app
  2. Code shared with carrier
  3. Carrier enters code at pickup
  4. Package secured, status updated
Security: Pickup codes expire after 24 hours for security. Generate a new code if needed.

Delivery Confirmation

Completing Delivery

At the delivery location:

  1. Carrier arrives at destination
  2. Recipient provided by shipper
  3. Carrier confirms delivery in app
  4. Optional photo proof captured
  5. Shipper receives completion notification

Troubleshooting

Location Not Updating?

  • Check carrier's location sharing settings
  • Ensure GPS is enabled on carrier's device
  • Wait a few minutes for refresh
  • Contact carrier through in-app messaging

No Status Updates?

  • Refresh the app
  • Check your internet connection
  • Verify notification permissions
  • Contact support if updates are delayed

Estimated Times

Accuracy of ETAs

  • Based on GPS and traffic data
  • Updates in real-time
  • Accounts for stops and delays
  • Weather and traffic conditions
  • Typically accurate within 10 minutes
