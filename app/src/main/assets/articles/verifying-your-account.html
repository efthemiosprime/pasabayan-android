Verifying Your Account

Account verification helps build trust and access advanced features. Pasabayan offers three verification levels to protect users and enable more opportunities.

Verification Levels

Basic (Unverified)

  • Account created with Google, Facebook, or Apple Sign-In
  • Can create and receive delivery requests
  • Limited to certain features
  • Some carriers may be reluctant to accept requests

Verified

  • Phone number verified via SMS OTP
  • Enhanced profile visibility
  • Access to all standard features
  • Increased trust from other users

Premium

  • ID verification completed
  • Government ID or driver's license verified
  • Highest level of trust
  • Priority in matching algorithm
  • Access to premium features

Phone Verification (Required for Verified)

  1. Go to Profile: Tap Profile tab
  2. Tap "Verification": See your current status
  3. Start Verification: Tap "Verify Phone Number"
  4. Enter Number: Add your phone number with country code
  5. Receive Code: SMS OTP will be sent
  6. Enter Code: Input 6-digit code within 10 minutes
  7. Success! Your account is now Verified
Tip: Use a valid number you can access. The code expires after 10 minutes, but you can request a new one.

Premium Verification

What You'll Need

  • Government-issued ID (driver's license, passport, or national ID)
  • Clear, well-lit photo of the ID
  • Selfie photo for verification
  • 5-10 minutes to complete

How to Upgrade

  1. Go to Profile → Verification
  2. Tap "Upgrade to Premium"
  3. Follow on-screen instructions
  4. Upload clear photos of your ID
  5. Take a selfie for comparison
  6. Submit for review
  7. Wait for approval (typically 24-48 hours)
Important: All verification data is encrypted and stored securely. We only share verification status with other users, never your personal documents.

Benefits of Verification

For Shippers

  • More carriers willing to accept requests
  • Better matching priority
  • Access to higher-rated carriers
  • Reduced security concerns

For Carriers

  • More delivery requests accepted
  • Higher earnings potential
  • Priority in browse results
  • Professional profile appearance

Troubleshooting

Didn't Receive Code?

  • Check your network connection
  • Verify phone number is correct
  • Wait 30 seconds before requesting again
  • Check spam messages
  • Contact support if issues persist

Verification Failed?

  • Ensure photo is clear and well-lit
  • All information must be visible
  • ID must not be expired
  • Selfie must match ID photo
  • Submit new photos if rejected

Privacy and Security
