Comment créer une demande de livraison

Pasabayan offre deux façons de faire livrer vos articles : Envoyer un colis pour expédier des paquets, ou Service de courses pour les courses d'épicerie, la livraison de nourriture, les collectes en pharmacie et plus encore. Suivez les étapes ci-dessous pour chaque option.

Pour commencer

Étape 1 : Accéder à l'onglet Colis

Ouvrez l'application Pasabayan et appuyez sur l'onglet « Colis » en bas de votre écran. C'est ici que vous gérez toutes vos demandes de livraison.

Étape 2 : Appuyer sur le bouton « CRÉER »

Appuyez sur le bouton flottant « CRÉER » dans le coin inférieur droit de l'écran. Une feuille apparaîtra avec deux options :

  • Envoyer un colis — Pour expédier des paquets et des articles vers un autre emplacement
  • Service de courses — Pour les courses d'épicerie, la livraison de nourriture, les collectes en pharmacie et les courses générales

Choisissez l'option qui correspond à vos besoins.

Option A : Envoyer un colis

Utilisez cette option lorsque vous devez envoyer un paquet ou un article d'un endroit à un autre.

Étape 3A : Ajouter des photos (optionnel)

Téléversez jusqu'à 5 photos de votre colis pour aider les transporteurs à savoir à quoi s'attendre. Chaque image peut peser jusqu'à 5 Mo au format JPG ou PNG.

Étape 4A : Remplir les détails du colis

Fournissez les informations suivantes :

  • Description du colis : Décrivez brièvement ce que vous envoyez (obligatoire)
  • Poids : Entrez le poids en kilogrammes (obligatoire)
  • Type de colis : Sélectionnez une catégorie — Électronique, Fragile, Documents, Livres, Vêtements, Nourriture, Meubles, Médical, Cadeaux et plus
  • Fragile : Activez si votre colis nécessite une manipulation soigneuse
  • Valeur du colis : Déclarez la valeur approximative (optionnel)
  • Budget maximum : Le maximum que vous êtes prêt à payer pour la livraison (optionnel)
  • Niveau d'urgence : Sélectionnez Faible, Normal, Élevé, Urgent, Express ou Flexible
  • Exigences de manipulation spéciale : Toute instruction spécifique pour le transporteur (optionnel)
Étape 5A : Définir les informations de collecte

Entrez les détails de votre collecte :

  • Pays : Sélectionnez dans le sélecteur de pays
  • Ville : Tapez pour rechercher — des suggestions apparaissent au fur et à mesure
  • Adresse : Entrez l'adresse complète de collecte
  • Code postal : (optionnel)
  • Point de repère : Un repère à proximité pour aider le transporteur à vous trouver (optionnel)
  • Date et heure de collecte préférées : Choisissez quand vous souhaitez que le colis soit récupéré
  • Collecte flexible : Activez si votre date de collecte est flexible
Étape 6A : Définir les informations de livraison

Entrez la destination de livraison avec les mêmes champs : pays, ville, adresse, code postal, point de repère, et date et heure de livraison préférées.

Étape 7A : Vérifier et soumettre

Un compteur d'exigences en haut affiche votre progression (ex. : « 3/5 »). Les 5 exigences doivent être remplies avant de pouvoir soumettre :

  • Description du colis remplie
  • Poids saisi
  • Adresse et ville de collecte fournies
  • Adresse et ville de livraison fournies
  • Dates valides sélectionnées

Une fois terminé, appuyez sur « Créer la demande » pour soumettre. Vous verrez une confirmation et le formulaire se réinitialisera automatiquement.

Vérification des doublons : Si une demande de colis similaire existe déjà, l'application vous avertira avant de créer un doublon. Vous pouvez choisir de continuer ou d'annuler.

Option B : Service de courses

Utilisez cette option lorsque vous avez besoin de quelqu'un pour faire des achats, récupérer quelque chose ou effectuer une course pour vous.

Étape 3B : Sélectionner le type de service

Choisissez le type de course dont vous avez besoin :

  • Courses d'épicerie — Quelqu'un fait vos courses d'épicerie
  • Livraison de nourriture — Récupérer une commande de nourriture pour vous
  • Collecte en pharmacie — Récupérer des ordonnances ou des articles en pharmacie
  • Course générale — Toute autre tâche pour laquelle vous avez besoin d'aide
Étape 4B : Créer votre liste d'achats

Ajoutez les articles dont vous avez besoin. Le titre de la liste change selon le type de service (ex. : « Liste d'articles » pour l'épicerie, « Liste de commande » pour la nourriture, « Liste d'ordonnances » pour la pharmacie).

Pour chaque article, fournissez :

  • Nom de l'article : Ce dont vous avez besoin (obligatoire)
  • Quantité : Combien (obligatoire)
  • Notes : Préférences de marque, taille ou autres détails (optionnel)

Appuyez sur « Ajouter un article » pour en ajouter d'autres. Vous pouvez supprimer des articles avec le bouton de suppression. Des suggestions peuvent apparaître au fur et à mesure que vous tapez pour vous aider à ajouter des articles plus rapidement.

Étape 5B : Définir le lieu de livraison

Indiquez au transporteur où livrer :

  • Adresse de livraison : Entrez votre adresse (des suggestions de saisie automatique apparaissent au fur et à mesure)
  • Ville de livraison : Tapez pour rechercher parmi les villes disponibles
  • Carte interactive : Vous pouvez également appuyer sur la carte pour sélectionner votre emplacement, ou utiliser le bouton « Utiliser ma position » pour une saisie rapide
Étape 6B : Paramètres optionnels

Développez la section « Détails optionnels » pour ajouter :

  • Magasin préféré : Nom et adresse du magasin si vous avez une préférence (le transporteur choisira si laissé vide)
  • Total estimé : Votre estimation du coût des articles
  • Budget maximum : Le maximum que vous êtes prêt à dépenser au total
  • Date de livraison : Quand vous avez besoin des articles livrés (le minimum est demain)
  • Instructions spéciales : Toute note supplémentaire pour le transporteur
Étape 7B : Soumettre votre demande

Une bannière d'exigences en haut suit votre progression (2 étapes requises) :

  • La liste d'achats contient des articles avec noms et quantités
  • Adresse et ville de livraison fournies

Une fois les deux exigences remplies, appuyez sur « Envoyer la demande » pour soumettre.

Après la soumission

Jumelage avec des transporteurs

Après la création de votre demande, elle devient visible pour les transporteurs voyageant sur des itinéraires compatibles. Vous pouvez :

  • Parcourir les trajets compatibles : Voir les transporteurs allant dans votre direction et demander un jumelage
  • Accepter ou refuser les offres : Lorsqu'un transporteur est intéressé, vous pouvez consulter son profil et décider

Suivi de votre demande

Une fois votre demande jumelée avec un transporteur, vous pouvez suivre sa progression :

  • Mises à jour du statut : Suivez de « Ouverte » → « Jumelée » → « Collecté » → « En transit » → « Livré »
  • Notifications : Recevez des mises à jour lorsque le statut de votre colis change
  • Clavardage : Envoyez des messages directement à votre transporteur via le clavardage intégré
Conseil : Ajoutez des instructions spéciales claires pour votre transporteur. Cela peut inclure des codes de portail, des préférences de livraison ou des notes de manipulation pour les articles fragiles.

Besoin d'aide?

Si vous rencontrez des problèmes ou avez des questions sur la création d'une demande de livraison :

  • Soumettez un ticket de support via l'application
  • Consultez les autres articles du Centre d'aide pour les questions fréquentes
