Accepter et effectuer des livraisons

Pasabayan met en relation des expéditeurs et des transporteurs grâce à un système de jumelage. Ce guide vous accompagne tout au long du processus de livraison — du jumelage à la confirmation — tant pour les expéditeurs que pour les transporteurs.

Comment fonctionne le jumelage

Un jumelage de livraison peut être initié de deux façons :

Initié par l'expéditeur

Un expéditeur parcourt les trajets disponibles des transporteurs et en trouve un le long d'un itinéraire compatible. L'expéditeur envoie une demande avec un prix proposé et un message optionnel. Le transporteur examine ensuite la demande et décide d'accepter, de refuser ou de faire une contre-offre.

Initié par le transporteur

Un transporteur parcourt les demandes de colis des expéditeurs et en trouve une qui correspond à son trajet. Le transporteur envoie une demande avec un prix proposé et un message optionnel. L'expéditeur examine ensuite la demande et décide d'accepter, de refuser ou de faire une contre-offre.

Répondre à une demande de jumelage

Lorsque vous recevez une demande de jumelage, vous avez trois options :

Accepter

Accepter le prix et les conditions proposés. Si les deux parties acceptent, le jumelage est confirmé automatiquement. Une conversation de clavardage est créée pour que vous puissiez coordonner les détails.

Contre-offre

Si le prix proposé ne vous convient pas, soumettez une contre-offre avec un nouveau prix et un message optionnel expliquant votre raisonnement. L'autre partie peut ensuite accepter, refuser ou faire une nouvelle contre-offre. Le nombre de tours de contre-offres par jumelage est limité.

Refuser

Refuser la demande. Vous pouvez fournir une raison pour votre refus. L'autre partie sera notifiée.

Conseil : Les contre-offres sont un excellent moyen de négocier un prix juste sans perdre le jumelage. Soyez raisonnable et expliquez pourquoi vous suggérez un montant différent.

Après la confirmation

Une fois que les deux parties sont d'accord et que le jumelage est confirmé :

  • Clavardage ouvert : Une conversation privée est créée pour que vous puissiez coordonner les détails de la collecte, l'horaire et les instructions spéciales
  • Paiement initié : Le paiement de l'expéditeur est autorisé automatiquement. Si l'expéditeur a un mode de paiement par défaut enregistré, cela se fait de manière transparente. Sinon, l'expéditeur devra effectuer le paiement avant de poursuivre
  • Mises à jour du statut : Vous pouvez suivre la progression de la livraison dans l'onglet Réservations
Paiement requis : L'expéditeur doit effectuer le paiement avant que le code de collecte puisse être généré. Si le paiement n'a pas été traité, l'expéditeur sera invité à payer lors de la tentative de génération du code de collecte.

Processus de collecte

La collecte utilise un code de confirmation à 6 chiffres sécurisé pour vérifier la remise du colis.

Pour les expéditeurs

Étape 1 : Générer le code de collecte

Lorsque vous êtes prêt pour que le transporteur récupère votre colis, générez un code de collecte à 6 chiffres depuis l'écran de détails de la livraison. Le code est automatiquement envoyé dans la conversation de clavardage pour que le transporteur puisse le voir.

Étape 2 : Partager le code avec le transporteur

Rencontrez le transporteur au lieu de collecte convenu et partagez le code. Vous pouvez également copier le code et l'envoyer manuellement si nécessaire.

Expiration du code : Les codes de collecte ont une durée de validité limitée. Un compte à rebours indique le temps restant. Si le code expire, vous pouvez en générer un nouveau.

Pour les transporteurs

Étape 1 : Obtenir le code

Le code de collecte de l'expéditeur apparaîtra automatiquement dans la conversation de clavardage. Rendez-vous au lieu de collecte convenu.

Étape 2 : Saisir le code

Saisissez le code à 6 chiffres dans l'écran de confirmation pour vérifier la collecte. Une fois vérifié, le statut de la livraison passe à « Collecté » et vous êtes responsable du colis.

Sécurité : Le système de code de confirmation garantit que les deux parties vérifient la remise en personne. Ne partagez jamais les codes avec quiconque autre que l'expéditeur ou le transporteur jumelé.

En transit

Après la collecte, le transporteur marque la livraison comme « En transit » pour indiquer qu'il est en route vers la destination.

Pour les transporteurs

  • Mettre à jour le statut : Marquez la livraison comme « En transit » depuis les détails de la réservation
  • Partage de position : Votre position est partagée automatiquement pendant le transit pour que l'expéditeur puisse suivre la progression de la livraison
  • Restez connecté : Utilisez le clavardage intégré pour communiquer toute mise à jour ou retard à l'expéditeur

Pour les expéditeurs

  • Suivre la progression : Visualisez la position actuelle du transporteur sur la carte en temps réel
  • Restez informé : Vous recevrez des notifications lorsque le statut change
  • Préparez-vous pour la livraison : Générez le code de livraison lorsque le transporteur approche (disponible une fois le statut « En transit »)

Processus de livraison

La confirmation de livraison utilise également un code de vérification à 6 chiffres, similaire au processus de collecte.

Pour les expéditeurs / destinataires

Étape 1 : Générer le code de livraison

Lorsque le transporteur approche, générez un code de livraison à 6 chiffres depuis l'écran de détails de la livraison. Le code est automatiquement envoyé dans la conversation de clavardage.

Étape 2 : Partager le code à la livraison

Lorsque le transporteur arrive, partagez le code pour confirmer que vous avez reçu votre colis.

Pour les transporteurs

Étape 1 : Arriver à destination

Rendez-vous à l'adresse de livraison et rencontrez le destinataire.

Étape 2 : Saisir le code de livraison

Saisissez le code à 6 chiffres fourni par le destinataire pour confirmer la livraison. Une fois vérifié, le statut de la livraison passe à « Livré ».

Ce qui se passe après la livraison

  • Clavardage fermé : La conversation de clavardage est automatiquement fermée avec un message système invitant les deux parties à laisser un avis
  • Paiement finalisé : Le paiement est capturé et vos gains sont traités
  • Invitation à évaluer : L'expéditeur et le transporteur sont invités à évaluer leur expérience

Statuts de livraison

Progression des statuts

  • En attente : Demande de jumelage initiale envoyée
  • Demandé : En attente de la réponse de l'autre partie (demandé par le transporteur ou l'expéditeur)
  • Accepté : Une partie a accepté, en attente de la confirmation finale
  • Confirmé : Les deux parties ont confirmé — prêt pour la collecte, paiement autorisé
  • Collecté : Le transporteur a récupéré le colis (vérifié par le code de collecte)
  • En transit : Le colis est en route vers la destination
  • Livré : Livraison réussie et confirmée (vérifié par le code de livraison)

Autres statuts

  • Annulé : Le jumelage a été annulé par l'une des parties avant la collecte
  • Refusé : La demande a été refusée par le transporteur ou l'expéditeur

Annulations

Quand pouvez-vous annuler

L'une ou l'autre des parties peut annuler un jumelage pendant la phase de négociation et de confirmation — avant que le colis n'ait été collecté. Les options d'annulation sont disponibles depuis l'écran de détails de la réservation.

  • Avant la collecte : Annulez librement avec traitement automatique du remboursement
  • Après la collecte : L'annulation n'est pas disponible une fois le colis récupéré

Annulation automatique

Si une demande de jumelage reste sans réponse trop longtemps, le système l'annulera automatiquement et traitera les remboursements applicables. Les deux parties sont notifiées lorsque cela se produit.

Clavardage intégré

Chaque livraison confirmée comprend une conversation de clavardage privée entre l'expéditeur et le transporteur. Utilisez-la pour :

  • Coordonner l'heure et le lieu de collecte
  • Partager les codes de confirmation (envoyés automatiquement par le système)
  • Communiquer les mises à jour ou les retards pendant le transit
  • Clarifier les instructions de livraison

Le clavardage reste actif tout au long de la livraison et est automatiquement fermé après la confirmation de livraison. L'historique des conversations est conservé pour vos dossiers.

Évaluations et avis

Après la confirmation de la livraison, les deux parties peuvent évaluer leur expérience :

  • Note par étoiles : Évaluez de 1 à 5 étoiles
  • Avis écrit : Ajoutez optionnellement un avis écrit sur votre expérience

Les évaluations contribuent à bâtir la confiance au sein de la communauté. Votre note moyenne et le nombre total d'avis sont affichés sur votre profil.

Conseil : Une bonne communication et des mises à jour ponctuelles mènent à de meilleures évaluations. Tenez l'autre partie informée tout au long du processus de livraison.

Référence rapide

Chronologie complète de la livraison

  1. Jumelage : L'expéditeur ou le transporteur envoie une demande avec un prix
  2. Négociation : Accepter, refuser ou faire une contre-offre
  3. Confirmation : Les deux parties sont d'accord — paiement autorisé, clavardage créé
  4. Collecte : L'expéditeur génère le code → Le transporteur saisit le code → Colis récupéré
  5. Transit : Le transporteur marque en transit → Position partagée → L'expéditeur suit
  6. Livraison : L'expéditeur génère le code → Le transporteur saisit le code → Livraison confirmée
  7. Évaluation : Les deux parties laissent des notes et des avis

Besoin d'aide?

Si vous rencontrez des problèmes pendant une livraison :

  • Utilisez le clavardage intégré pour communiquer avec l'autre partie
  • Vérifiez le statut de la livraison dans votre onglet Réservations
  • Soumettez un ticket de support via l'application si vous avez besoin d'assistance
