Accepting and Completing Deliveries

Pasabayan connects shippers and carriers through a matching system. This guide walks you through the entire delivery process — from matching to confirmation — for both shippers and carriers.

How Matching Works

There are two ways a delivery match can start:

Shipper-Initiated

A shipper browses available carrier trips and finds one along a compatible route. The shipper sends a request with an offered price and an optional message. The carrier then reviews the request and decides to accept, decline, or counter-offer.

Carrier-Initiated

A carrier browses package requests from shippers and finds one that fits their trip. The carrier sends a request with a proposed price and an optional message. The shipper then reviews the request and decides to accept, decline, or counter-offer.

Responding to a Match Request

When you receive a match request, you have three options:

Accept

Agree to the proposed price and terms. If both parties accept, the match is confirmed automatically. A chat conversation is created so you can coordinate details.

Counter-Offer

If the proposed price doesn't work for you, submit a counter-offer with a new price and an optional message explaining your reasoning. The other party can then accept, decline, or counter again. There is a limited number of counter-offer rounds per match.

Decline

Turn down the request. You can provide a reason for declining. The other party will be notified.

Tip: Counter-offers are a great way to negotiate a fair price without losing the match entirely. Be reasonable and explain why you're suggesting a different amount.

After Confirmation

Once both parties agree and the match is confirmed:

  • Chat opens: A private chat conversation is created for you to coordinate pickup details, timing, and any special instructions
  • Payment initiated: The shipper's payment is authorized automatically. If the shipper has a default payment method on file, this happens seamlessly. Otherwise, the shipper will need to complete payment before proceeding
  • Status updates: You can track the delivery progress in the Bookings tab
Payment Required: The shipper must complete payment before the pickup code can be generated. If payment hasn't been processed, the shipper will be prompted to pay when attempting to generate the pickup code.

Pickup Process

The pickup uses a secure 6-digit confirmation code to verify the handoff.

For Shippers

Step 1: Generate the Pickup Code

When you're ready for the carrier to pick up your package, generate a 6-digit pickup code from the delivery details screen. The code is automatically sent to the chat conversation so the carrier can see it.

Step 2: Share the Code with the Carrier

Meet the carrier at the agreed pickup location and share the code. You can also copy the code and send it manually if needed.

Code Expiry: Pickup codes have a limited validity period. A countdown timer shows the remaining time. If the code expires, you can generate a new one.

For Carriers

Step 1: Get the Code

The shipper's pickup code will appear in the chat conversation automatically. Meet the shipper at the agreed pickup location.

Step 2: Enter the Code

Enter the 6-digit code in the confirmation screen to verify the pickup. Once verified, the delivery status changes to "Picked Up" and you're responsible for the package.

Security: The confirmation code system ensures that both parties verify the handoff in person. Never share codes with anyone other than the matched shipper or carrier.

In Transit

After pickup, the carrier marks the delivery as "In Transit" to indicate they're on their way to the destination.

For Carriers

  • Update status: Mark the delivery as "In Transit" from the booking details
  • Location sharing: Your location is shared automatically during transit so the shipper can track delivery progress
  • Stay connected: Use in-app chat to communicate any updates or delays to the shipper

For Shippers

  • Track progress: View the carrier's current location on the map in real time
  • Stay informed: You'll receive notifications when the status changes
  • Prepare for delivery: Generate the delivery code when the carrier is approaching (available once the status is "In Transit")

Delivery Process

Delivery confirmation also uses a 6-digit verification code, similar to the pickup process.

For Shippers / Recipients

Step 1: Generate the Delivery Code

When the carrier is approaching, generate a 6-digit delivery code from the delivery details screen. The code is automatically sent to the chat conversation.

Step 2: Share the Code at Delivery

When the carrier arrives, share the code to confirm you've received your package.

For Carriers

Step 1: Arrive at Destination

Head to the delivery address and meet the recipient.

Step 2: Enter the Delivery Code

Enter the 6-digit code provided by the recipient to confirm the delivery. Once verified, the delivery status changes to "Delivered".

What Happens After Delivery

  • Chat closes: The chat conversation is automatically closed with a system message prompting both parties to leave a review
  • Payment finalized: The payment is captured and your earnings are processed
  • Rating prompt: Both the shipper and carrier are prompted to rate their experience

Delivery Statuses

Status Progression

  • Pending: Initial match request sent
  • Requested: Awaiting the other party's response (carrier requested or shipper requested)
  • Accepted: One party has accepted, awaiting final confirmation
  • Confirmed: Both parties confirmed — ready for pickup, payment authorized
  • Picked Up: Carrier has collected the package (verified by pickup code)
  • In Transit: Package is on its way to the destination
  • Delivered: Successfully delivered and confirmed (verified by delivery code)

Other Statuses

  • Cancelled: Match was cancelled by either party before pickup
  • Declined: Request was declined by the carrier or shipper

Cancellations

When You Can Cancel

Either party can cancel a match during the negotiation and confirmation phase — before the package has been picked up. Cancellation options are available from the booking details screen.

  • Before pickup: Cancel freely with automatic refund processing
  • After pickup: Cancellation is not available once the package has been collected

Auto-Cancellation

If a match request goes unanswered for too long, the system will automatically cancel it and process any applicable refunds. Both parties are notified when this happens.

In-App Chat

Every confirmed delivery includes a private chat conversation between the shipper and carrier. Use it to:

  • Coordinate pickup time and meeting point
  • Share confirmation codes (auto-sent by the system)
  • Communicate updates or delays during transit
  • Clarify delivery instructions

The chat remains active throughout the delivery and is automatically closed after delivery confirmation. Conversation history is preserved for your records.

Ratings and Reviews

After delivery is confirmed, both parties can rate their experience:

  • Star rating: Rate from 1 to 5 stars
  • Written review: Optionally add a written review about your experience

Ratings help build trust in the community. Your average rating and total number of reviews are displayed on your profile.

Tip: Good communication and timely updates lead to better ratings. Keep the other party informed throughout the delivery process.

Quick Reference

Complete Delivery Timeline

  1. Match: Shipper or carrier sends a request with a price
  2. Negotiate: Accept, decline, or counter-offer
  3. Confirm: Both parties agree — payment authorized, chat created
  4. Pickup: Shipper generates code → Carrier enters code → Package collected
  5. Transit: Carrier marks in transit → Location shared → Shipper tracks
  6. Deliver: Shipper generates code → Carrier enters code → Delivery confirmed
  7. Rate: Both parties leave ratings and reviews

Need Help?

If you encounter any issues during a delivery:

  • Use in-app chat to communicate with the other party
  • Check the delivery status in your Bookings tab
  • Submit a support ticket through the app if you need assistance
